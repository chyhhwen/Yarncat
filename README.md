# 毛球貓 YarnCat

一隻住在螢幕底部的原創像素貓。你辦公，牠在旁邊玩毛球：盯著球、壓低身體扭屁股、飛撲、用前掌撥，玩累了就趴下睡覺。也可以換成雷射光或逗貓棒，用滑鼠陪牠玩。

支援 Windows 10 / 11。macOS 版（M 系列、Intel 都可以）是測試版，作者沒有 Mac 實際測過，有問題請到 [Issues](../../issues) 回報。

## 安裝

### Windows

1. 到 [Releases](../../releases) 下載最新的 `YarnCat_x.x.x_x64-setup.exe`。
2. 雙擊安裝。
3. 因為安裝檔沒有程式碼簽章，Windows 可能會跳出「Windows 已保護您的電腦」。按「其他資訊」→「仍要執行」即可。
4. 如果跳出的是「**智慧型應用程式控制**已封鎖可能不安全的應用程式」，這個畫面沒有「仍要執行」可以按。
   這是 Windows 11 一項較嚴格的防護，會擋下所有沒有簽章的程式。要安裝毛球貓只能把它關掉：
   「Windows 安全性」→「應用程式與瀏覽器控制」→「智慧型應用程式控制設定」→「關閉」。
   - 關掉會降低整台電腦的防護，請自行斟酌。
   - 在某些 Windows 版本上，關掉之後要重設 Windows 才能再打開，畫面上會有說明。
   - 不想關的話，可以用瀏覽器直接打開 `src/index.html` 玩網頁版（沒有點擊穿透，貓會擋住後面的視窗）。

### macOS（測試版）

1. 到 [Releases](../../releases) 下載最新的 `YarnCat_x.x.x_universal.dmg`。
2. 打開 dmg，把 YarnCat 拖進「應用程式」。
3. 因為安裝檔沒有簽章，直接打開會說「YarnCat 已損毀」。先打開「終端機」執行一次：
   ```
   xattr -cr /Applications/YarnCat.app
   ```
   之後就能正常打開。

## 怎麼玩

- 貓和毛球只在工作列上方一條窄區活動，透明的地方滑鼠會直接點到後面的程式。
- 拖住貓可以把牠拎起來，放開會掉下去。
- 抓住毛球甩出去，貓會追。
- 每隔一兩分鐘，貓會冒出一個泡泡：
  - **愛心泡泡**：牠想被摸。點一下泡泡，牠會瞇眼呼嚕、冒愛心。
  - **妙脆角泡泡**：牠盯著想像中的妙脆角流口水。點一下泡泡，就會掉一根妙脆角下來，牠會走過去喀滋喀滋吃掉，吃完舔舔嘴。
  - **大泡泡**：牠望著臉前面的大泡泡發呆，泡泡裡是你放進「泡泡圖片資料夾」的其中一張圖片（大約每三個泡泡有一個，隨機挑，盡量不連續兩次同一張）。點一下泡泡就會啵一聲破掉。資料夾裡沒有圖片的話，只會冒上面兩種小泡泡。
  - 沒理牠的話，泡泡過一陣子就自己消失。
- 不用按，游標在貓身上左右來回滑幾下就是在摸牠，一直摸牠就一直呼嚕（睡覺、趴著、翻肚的時候也可以摸）。
- 系統匣的貓咪圖示（Windows 在右下角，macOS 在右上角選單列）：
  - **玩具**：換成別的玩具。
    - **毛球**：預設的玩具。
    - **雷射光**：紅點照在滑鼠游標的位置。貓會追過去，跳起來拍，但永遠抓不到。
    - **逗貓棒**：逗貓棒跟著滑鼠走，羽毛垂在游標下方。貓會追著跑，跳起來抓住羽毛吊在上面；甩太快牠就會鬆手。
    - 雷射光、逗貓棒拿太高（或跑出畫面外）搆不到時，貓會坐著仰頭看，有時候趴成一條麵包盯著。盯太久就放棄，翻肚四腳朝天望著天空，之後一陣子懶得理搆不到的東西；只要東西低下來，牠就會翻回來去抓。
  - **螢幕**：有接副螢幕時，選貓要待在哪個螢幕。預設是主螢幕；重開毛球貓會回到主螢幕。毛球貓開著時才接上的螢幕，要重開才會出現在清單裡。
  - **打開泡泡圖片資料夾**：大泡泡的圖片從這裡挑。資料夾是「圖片」底下的 `YarnCat`（Windows 是 `圖片\YarnCat`，macOS 是 `~/Pictures/YarnCat`），第一次按的時候會自動建立。
    - 支援 PNG、JPG、GIF、WebP、BMP，單張 20 MB 以內。GIF 動圖只會顯示第一格。
    - 照片會縮小放進泡泡；很小的圖（例如 48×28 以內的像素畫）會放大整數倍，跟貓一樣一格一格的。
    - 放進去、刪掉都不用重開毛球貓，下一次冒泡泡就算數。
  - **安靜模式**：開會或分享螢幕時讓貓去睡覺。
  - **結束毛球貓**。

## 原理

| 部分 | 檔案 | 做什麼 |
| --- | --- | --- |
| 透明長條視窗 | `src-tauri/tauri.conf.json` | 透明、無邊框、置頂、不出現在工作列 |
| 擺放位置 | `src-tauri/src/main.rs` `pick_monitor`、`strip_rect`、`Placer` | 在系統匣選的螢幕（預設主螢幕）扣掉工作列的範圍，擺在最底部；每秒檢查一次，換螢幕、改縮放、搬工作列後自動重擺 |
| 點擊穿透 | `main.rs` `watch_cursor` + `src/index.html` `hitTest` | Rust 每 16ms 回報游標位置（毛球模式只在游標進到長條時回報），前端判斷在不在貓或毛球上，再開關穿透 |
| 貓的行為 | `src/index.html` `updateCat`、`nextHunt` | 狀態機：坐、舔毛、盯、追、撲、撥、睡；雷射光、逗貓棒另外有追、壓低、跳起來拍、抓住吊著，搆不到時趴成麵包盯著、翻肚放棄 |
| 毛球 | `src/index.html` `updateBall` | 重力、摩擦、反彈，線頭用 Verlet 積分 |
| 雷射光、逗貓棒 | `src/index.html` `updateLaser`、`updateWand` | 紅點、逗貓棒的線都掛在游標上（`watch_cursor` 回報的位置） |
| 泡泡、摸貓、妙脆角 | `src/index.html` `bubbleBox`、`stroke`、`popBubble`、`updateFx` | 閒著時偶爾進入討摸（`beg`）、流口水（`drool`）或望著圖片發呆（`dream`）狀態並畫出泡泡；點泡泡、或游標在貓身上來回滑就觸發被摸（`pet`）、走去吃（`fetch` → `eat`） |
| 大泡泡的圖片 | `main.rs` `list_pictures`、`read_picture`、`open_picture_dir` + `src/index.html` `preparePic`、`fitPic`、`showPic` | 快冒泡泡前先擲骰子，擲到大泡泡才從資料夾隨機挑一張讀進來、縮成泡泡大小。圖片用螢幕實際的解析度畫在主畫布底下的另一個 canvas，主畫布在泡泡裡挖洞讓它透出來，照片才不會變成馬賽克 |
| 系統匣選單 | `src-tauri/src/main.rs` `main` | 換玩具、換螢幕、打開泡泡圖片資料夾、安靜模式、結束，用事件通知前端 |

直接用瀏覽器打開 `src/index.html` 也能玩（沒有點擊穿透），改行為時這樣測最快。按 `1` `2` `3` 切換毛球、雷射光、逗貓棒，按 `4` `5` 直接叫出愛心泡泡、妙脆角泡泡。網頁版沒有泡泡圖片資料夾，改成把圖片拖進視窗（重新整理就要再拖一次）：拖進去會馬上冒一次大泡泡，之後按 `6` 再叫出來。

## 自己編譯

需要 [Rust](https://www.rust-lang.org/tools/install) 和 [Node.js](https://nodejs.org/)：

```
npm install
npm run tauri dev
```

## 隱私

毛球貓不會連上網路，也不會收集、儲存或傳送任何資料。

- 程式裡沒有任何網路連線、統計或自動更新功能。
- 游標位置只用來讓貓追玩具、判斷你有沒有點到貓，不會記錄下來。
- 泡泡圖片資料夾裡的圖片只在你的電腦上讀取、畫在泡泡裡，不會傳到任何地方。
- 例外是安裝程式：電腦裡沒有 Microsoft Edge WebView2 時，安裝程式會向微軟下載安裝。這是 Windows 顯示畫面用的元件，下載過程由微軟處理。
